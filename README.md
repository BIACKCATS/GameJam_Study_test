## 게임 소개
> 2026 해커톤 게임 인재원 출품작입니다. 

**최공익을 이끌어 다양한 사람들을 만나 대화를 나누며 수많은 성공과 실패를 겪는 것을 목표로 둔 게임입니다.** 해당 게임에는 1번 고정관념과 장벽 깨기: '캐릭터도, 플레이도, 누구나 자유롭게' 라는 내용입니다.
부가적으로 2번 내용의 플레이의 문을 넓히기 : '더많은 사람들이 함께 즐길 수 있게' 라는 목표도 하나하나 적용이 가능할 수 있게 하는 것으로 세부 목표를 잡은 게임입니다.

평소 유저들에게 짙은 개그성을 기반으로 다양성에 접근한 경험을 주고자 해당 게임을 만들었습니다.

## 플레이 방식

| 순서 | 입력 키 | 설명 |
|---|---|---|
| 1 | **A, D키 입력** | A키를 눌러 왼쪽 방향으로 이동하고, D키를 눌러 오른쪽 방향으로 이동이 가능합니다. | 
| 2 | **SHIFT + 좌클릭** | 쉬프트 키를 누른채로 좌클릭을 통해 지하철의 여러 인물들과 상호작용을 할 수 있습니다. | 
| 3 | **좌클릭** | 대화하면서 판정 구간에 도달할 경우, 막대기 바를 가운대에 도달하였을 때 클릭하여주세요. |

### 프로젝트 & 시나리오
- 주제 기반으로 모든 행위를 최대한 주제에서 벗어나지 않기 위해 노력할 것. 적어도, 해당 주제가 게임의 목표가 될 수 있도록 해야 할 것.
- 트리형 구조 인터랙티브 대화 스크립트 제작 — CSV 파일 연동하여 각 반응에 맞는 대화 스크립트 작성

- 단순히 국민들을 위해 봉사하는 사회 복무요원들과 각자들의 사정이 담겨있는 지하철 빌런 사이와의 코미디 스러운 전개로 친숙하게 다가옴과 동시에 희화화를 통한 재미를 유도하였습니다.
